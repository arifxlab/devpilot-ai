# DevPilot AI

> A modular personal AI agent designed to understand software projects through tools, memory, and extensible AI providers.

## Overview

DevPilot AI is a backend AI agent built with Python and FastAPI.

The goal of the project is to create a practical engineering assistant capable of interacting with a software project through tools instead of relying only on conversational responses.

The current version focuses on:

- Agent orchestration
- Tool execution
- Project inspection
- File understanding
- Extensible AI provider architecture
